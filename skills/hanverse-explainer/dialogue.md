# 写问答

问题写在 `src/data/questions/<主题>.ts`，类型见同目录 `types.ts`。写完跑：

```
node tests/dialogue-rules.mjs src/data/questions/<主题>.ts
```

## 字段

| 字段 | 写什么 |
|---|---|
| `id` | 英文短横线，如 `oracle-bones`、`horse-stands`；也是动画和配音的文件名 |
| `topic` | 11 个主题之一，和文件一致：`origin` `picture` `point` `together` `sound` `change` `parts` `write` `fun` `story` `art` |
| `difficulty` | 1 入门、2 进阶、3 挑战。列表按它排序，每个主题第一个问题要是 1 |
| `title` | 小念口吻的问题，必须带"？" |
| `trigger` | 小念刚遇到的那件事，一句话，具体到场景："写作业时，小念发现'妈''吗''骂'里都藏着一匹'马'" |
| `chars` | 这一问讲到的字，简体，1～12 个。每个字都要在标题或问答里出现；页面会列出来，点进去是「一个字的一生」 |
| `dialogue` | 5–8 轮 `{ nian, dad, show? }` |
| `parentTip` | 给大人：学界的说法和争议、数字的出处、可以怎么陪孩子玩 |

## 检查器会拦的

- 5–8 轮；每轮小念和爸爸都要有话。
- 除最后一轮外，小念每句都是问句，带"？"。
- 最后一轮小念要以"我懂了"或"我明白了"开头，用自己的话总结。
- 从第 2 轮起，小念的问题必须用上爸爸上一句里的一个两字词（"汉字""样子""时候"这种人人都说的词不算）。
- 爸爸每句 20–170 字。
- 不用术语表里的词：构拟、声母、韵部、反切、谐声、籀文、隶变、声符、义符……要换成孩子听得懂的说法（"表示读音的那一半"）。"象形""指事""会意""形声""偏旁""部首"可以用，但第一次出现要先讲明白。
- `chars` 里的字都要在问答里出现，不能重复。
- `show` 里的 `steps` 至少 2 格；`forms` 2～5 个，每个古文字都要在字体里有（规则同动画，见 film.md）。

## 写好的标准（检查器管不到的）

**小念**：
- 7 岁男孩的口气，短句，带情绪："哇，真的像一匹马！""那三棵树呢？"
- 追问要"顺着往下挖"，不要跳题。好的追问来自爸爸刚说的那个新词：爸爸说了"竹简"，小念就问"竹简是什么样的？"。

**爸爸**：
- 先回答问题本身，第一句就给答案，再解释。
- 说字的时候用引号：“日”“休”。说字的样子用孩子能画出来的话："一个圆圈，中间一个点"。
- 一个比方只讲一件事，用孩子见过的东西：画画、拼积木、贴标签、表情包、路牌。
- 比方说完说真名，只说一次："……这种字叫会意字。"
- 数字要真实，出处写在 `parentTip` 或 [facts.md](facts.md) 里。屏幕和动画里出现的数字只能是爸爸说过的。
- 造字的解释有争议的，要说出来："《说文》说是……，可是看了甲骨文，很多学者觉得是……"。
- 结尾给一个能马上做的小事：找一找课本里带三点水的字、用手指在桌上写一遍、猜一个字谜。

**追问链的常见顺序**（不必每次都全用）：
1. 这个字像什么、是什么意思
2. 古人为什么这样造（当时怎么生活、用什么写字）
3. 后来怎么变成今天的样子
4. 常见误会或例外
5. 我能怎么用（认字、写字、记字的窍门）
6. 小念总结，爸爸给一个小游戏

**`show`**：
- 爸爸讲"一步一步"时，配 `steps`：2–4 格，每格一个 emoji 加 ≤8 字。
- 爸爸讲"这个字以前长这样"时，配 `forms`：一排字形，比如 `[{ icon: "🐴" }, { script: "oracle", char: "馬" }, { script: "seal", char: "馬" }, { script: "kai", char: "马" }]`。

## 例子（`origin.ts` 的 `oracle-bones`，节选）

```ts
{
  id: "oracle-bones", topic: "origin", difficulty: 1,
  title: "龟壳上怎么会刻着字？",
  trigger: "在博物馆里，小念看到一块裂着缝的龟壳，上面刻满了小小的字。",
  chars: ["卜", "龟", "骨", "兆", "雨"],
  dialogue: [
    {
      nian: "爸爸，这块龟壳上怎么刻着字？是谁刻的呀？",
      dad: "这是三千多年前商朝人刻的，叫甲骨文。“甲”是乌龟肚子底下那块硬甲，“骨”是牛肩膀上的大骨头。商朝的王遇到大事拿不定主意，就用它们来占卜，问问老天和祖先。"
    },
    {
      nian: "占卜是什么？龟壳怎么会回答问题？",
      dad: "占卜就是想办法猜答案。他们先在龟甲背面挖出一排小坑，再用烧红的木棍去烫。小坑一受热，正面就“啪”地裂出一道缝。王看裂缝往哪边走，就说这件事是好还是坏。"
    },
    {
      nian: "那道裂缝长什么样？",
      dad: "一竖，旁边斜出一个小杈，就像这样。古人照着它的样子造了一个字，就是“卜”。这种裂纹古人叫“兆”，我们今天说“好兆头”，就是从这里来的。",
      show: { kind: "forms", forms: [{ icon: "⚡", label: "裂纹" }, { script: "oracle", char: "卜" }, { script: "seal", char: "卜" }, { script: "kai", char: "卜" }] }
    },
    // ……刻了什么 → 怎么被发现 → 认出了多少……
    {
      nian: "我懂了！商朝人用龟甲和牛骨占卜，烫出裂纹，再把问的事刻在旁边，这就是甲骨文。",
      dad: "说得真好。不过甲骨文已经是很成熟的文字了，在它以前，汉字一定还走过很长的路。下次我们聊聊，汉字到底是谁造的。"
    }
  ],
  parentTip: "甲骨文是商代后期（约公元前 14～前 11 世纪）的占卜记录……"
}
```

注意第 2 轮小念的"占卜"、第 3 轮的"裂缝"都是爸爸上一句的原话，这就是追问链。
