# 页面风格

和身体奇遇记、化学奇遇记是一家：暖色、圆角、手写体、气泡对话。汉字奇遇记在这个基础上多了一点"纸和墨"的味道。

- **字体**：正文是 Comic Neue + 马善政毛笔楷书（`index.css` 的 `--app-font-family`）。古文字用 `src/lib/scripts.ts` 里的字族：`HanOracle`（甲骨文）、`HanSeal`（动画用的小篆子集）、`HanSealFull`（查字页用的完整小篆）。
- **颜色**：
  - 墨色 `#4a3b2a` 写字；
  - 朱红 `#d9453a` 是汉字奇遇记的强调色（查字按钮、田字格、标红笔画）；
  - 宣纸 `#fffdf6` → `#f3e2c1` 做底；
  - 主题卡片各有自己的颜色（`src/data/questions/types.ts` 的 `topics`）。
- **字的小格子**：页面上单独列出来的字（"这一问里的字"、谐声一家字）放在带淡红十字线的方格里，像田字格，点进去是查字页。
- **气泡**：小念的气泡在右边、米黄色；爸爸的在左边、白色。正在说话的那句加橙色描边。
- **动画舞台**：4:3，圆角 16，左上角是场次标题胶囊。底图都是 SVG 画的，跟着镜头一起缩放。
- **手机宽度**（390px）：卡片一列；查字页的三个阶段还是并排，字形缩小；字幕会自动放大，不用另外处理。
- **动作**：尊重 `prefers-reduced-motion`：不自动播放动画，气泡不浮动，查字页"看它长大"直接跳。
