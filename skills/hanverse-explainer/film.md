# 做讲解动画

动画写在 `src/data/films/<主题>.ts`，类型见 `src/data/films/types.ts`，汇总在 `index.ts`。写完跑：

```
node tests/film-rules.mjs src/data/films/<主题>.ts
```

## 结构

```ts
export const films: readonly Film[] = [
  {
    question: "oracle-bones",            // 问题 id
    scenes: [
      {
        turn: 0,                          // 配第几轮问答（从 0 数）
        title: "会说话的龟甲",             // ≤12 字
        view: "shell",                    // 底图，不写就是宣纸
        duration: 10,                     // 4～14 秒
        camera: [{ t: 0, at: [600, 450], zoom: 1 }, { t: 2, at: [760, 520], zoom: 2 }],  // 可选
        cues: [ /* 元素 */ ]
      }
    ]
  }
];
```

- 画面是 **1200×900**，坐标一律写 `[x, y]`，左上角是 `[0, 0]`。
- 至少 4 场戏，全片 30～110 秒（这是没配音时的长度，配音版会自动拉长）。
- 第一场配第 0 轮；场次按对话顺序；最多只能有一轮不配戏（通常是最后的总结）。
- 每场至少 2 个元素，同一时刻最多 8 个（最好不超过 6 个）。
- 元素的 `from` / `to` 是从这场戏开头算的秒数；不写 `to` 就留到这场戏结束。`from` 不能晚于结束前 0.8 秒。

## 底图

| `view` | 画的是 | 能放东西的地方 |
|---|---|---|
| 不写 / `paper` | 米黄色宣纸，什么都没有 | 整个画面 |
| `shell` | 深棕色背景上一整块龟腹甲 | 甲在 x 295–905、y 40–870；中缝 x=600；背面的小坑在 [470,300] [730,300] [440,520] [760,520] [480,720] [720,720] |
| `slips` | 一排 8 根竖着的竹简，上下两道绳子 | 每根宽 112、间隔 14，第 i 根中心 x = 159 + 126·i（159、285、411、537、663、789、915、1041）；y 40–860，绳子在 y=150 和 y=750 |
| `grid` | 中间一个红色田字格 | 格子是 x 280–920、y 130–770，中心 [600, 450]，边长 640 |

## 元素

### 字

| `kind` | 用来 | 关键字段 |
|---|---|---|
| `glyph` | 显示一个字 | `char`、`at`、`script`（`oracle` 甲骨文 / `seal` 小篆 / `kai` 楷书，默认 / `song` 印刷体）、`size`（默认 220）、`color`、`caption`（字下面的小字，≤8 字）、`path` + `travel`（从 `at` 沿路线挪过去）、`rotate` / `turnTo` / `over`（转身）、`mirror: true`（左右翻过来，印章、活字上的反字）、`motion`（`pulse` / `wiggle`） |
| `evolve` | 同一个字一步步变样子 | `at`、`forms`（2～5 种）、`size`（默认 260）、`every`（每种停几秒，默认 1.6）。下面自动有一排小标签，当前那种亮起来 |
| `write` | 按笔顺一笔一笔写（楷书） | `char`、`at`、`size`（字框边长，默认 420）、`stroke`（每笔几秒，默认 0.7）、`upTo`（只写前几笔）、`mark`（要标红的笔画，从 0 数）、`color`、`grid`（自带田字格） |

`forms` 里每一项是 `{ icon: "🐴" }`（图画）或 `{ script: "oracle", char: "馬" }`，可以加 `label` 改小标签（≤4 字，默认是"图画""甲骨文""小篆""楷书""印刷体"）。

**字体规则（检查器会拦，并告诉你怎么改）**：
- 甲骨文和小篆的字体是**按繁体字**编的：写 `馬` `魚` `鳥` `龜` `車` `見`，不写 `马` `鱼` `鸟`。
- 甲骨文一共只有 1425 个字能显示。没有的（比如 `本` `末` `江` `看` `信`）就用小篆，或者换一个字讲。
- 楷书（`kai`）用的是马善政毛笔楷书，**只有简体**，写今天的字形。要显示繁体用 `song`。
- 动画用到新的小篆字以后要跑 `npm run fonts`（切字体子集，约 1 分钟）；用到新的 `write` 字要跑 `npm run strokes`（要联网）。

### 指、圈、画

| `kind` | 用来 | 关键字段 |
|---|---|---|
| `label` | 贴在某处的标签，带引线 | `at`、`text`（≤12 字）、`side`（`left`/`right`/`top`/`bottom`）或 `pos` |
| `highlight` | 一圈柔光，圈出字的一部分 | `at`、`size`（宽高，默认 [240,240]）、`color` |
| `pulse` | 一圈圈波纹：提醒、声音 | `at`、`radius`、`color` |
| `line` | 一笔画出来的线，没箭头：裂纹、记号、刻痕 | `path`、`width`（默认 6）、`color`、`draw`（画几秒） |
| `arrow` | 一笔画出来的箭头 | `path`、`text`（≤10 字）、`draw` |
| `flow` | 一串小点（或小图标）沿路线一直流 | `path`、`icon`、`count`、`speed` |
| `sprite` | 一个 emoji：一个点就原地弹出，多个点就沿路线走 | `icon`、`path`、`size`、`travel`、`wobble`、`spin`、`rotate` / `turnTo` |
| `shape` | 示意图形：屋顶、竹片、方框 | `shape`（`circle`/`rect`/`pill`）、`at`、`size`、`color`、`text`（≤6 字）、`motion`、`outline`（虚线边，底色照填；只框住别的字时 `color: "none"`，后画的形状会盖住先画的字） |

### 字幕

`text`、`count`、`meter` 的 `at` 是**屏幕位置**（同样按 1200×900），镜头怎么推都留在原处。

| `kind` | 用来 | 关键字段 |
|---|---|---|
| `text` | 一行大字，点出关键词 | `text`（≤14 字）、`size`（`s`/`m`/`l`）、`color` |
| `count` | 数字从 start 数到 end | `label`（≤8 字）、`start`、`end`、`unit` |
| `meter` | 进度条，0～1 | `label`（≤8 字）、`start`、`end`、`color` |
| `myth` | 常见误会：先划掉错的，再亮出对的（显示在画面底部） | `wrong`、`right`（各 ≤18 字） |

### 镜头

`camera` 是关键帧列表，`zoom` 1～2.6。要看字的一个部件（"刃"上那一点）时推近，讲完拉远。检查器会算镜头，元素出现半秒后不在镜头里就报错。

## 配方

**图画变成字**（象形）：
```ts
{ kind: "evolve", at: [600, 400], size: 300, every: 1.8, from: 0.5,
  forms: [{ icon: "☀️" }, { script: "oracle", char: "日" }, { script: "seal", char: "日" }, { script: "kai", char: "日" }] }
```
`evolve` 下面自带标签，所以 `at` 的 y 别太靠下（≤560）。

**两个字拼成一个字**（会意、形声）：两个 `glyph` 从两边挪到一起，再出合成的字。
```ts
{ kind: "glyph", char: "人", at: [250, 420], path: [[520, 420]], travel: 1.5, from: 0.5, to: 4.5 },
{ kind: "glyph", char: "木", at: [950, 420], path: [[680, 420]], travel: 1.5, from: 0.8, to: 4.5 },
{ kind: "glyph", char: "休", at: [600, 420], size: 320, from: 4.5, motion: "pulse" }
```
形声字可以给两半上不同颜色：管意思的一半用 `#2f7d32`，管读音的一半用 `#b48cff`。

**指事记号**：先出 `木`，再用 `line` 在下面画一短横，`label` 写"树根在这里"，最后出 `本`。

**站起来的马**：`{ kind: "glyph", char: "馬", script: "oracle", at: [600, 430], rotate: -90, turnTo: 0, over: 1.5, from: 1 }` —— 先横着（像真的马），再转成竖着写。甲骨文字体里马、豕、虎都是头朝上、腿在左边，所以横过来要用 `-90`（逆时针）；写成 `90` 会四脚朝天。

**笔顺**：底图用 `grid`，`{ kind: "write", char: "十", at: [600, 450], size: 640, stroke: 1, from: 0.5 }`，大小等于格子边长时正好写在田字格里。每一笔开头有一个圆形序号。讲"第二笔"时用 `mark: [1]` 把它标红。

**甲骨上的裂纹**：两条 `line`，一竖加一个斜出的小杈，颜色 `#3b2a1a`，就是"卜"的样子。

## 排版

- 字要大：主角字 `size` 260～340，并排的字 160～220，一列小字 110～140。
- 字之间留足空：两个 size 220 的字中心至少隔 260。
- `text` 放在画面上方（y≈110）或下方（y≈800），别压在字上；`myth` 卡显示在底部，那几秒下方别放 `text`。
- 深色的 `shell` 底图上，龟甲外面的地方适合放 emoji，不适合放小字。
